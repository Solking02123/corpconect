# دليل تشغيل نظام CorpConnect بلغة بايثون (Python)

تمت برمجة هذا الإصدار المباشر بلغة **Python** ليعمل بشكل محلي ومستقل على جهازك بدون الحاجة لتثبيت بيئة Node.js أو أي مكتبات خارجية معقدة.

---

## 📥 طريقة تحميل المشروع من المنصة:
1. من أعلى واجهة الموقع أو القائمة الجانبية (Settings / خيارات المشروع)، اضغط على **Export** أو **Download ZIP** (أو خيار التصدير إلى GitHub ثم تحميل الـ ZIP).
2. قم بفك الضغط (Extract) عن الملف المضغوط على جهاز الكمبيوتر الخاص بك.

---

## 🚀 طريقة التشغيل السريع:

### على نظام ويندوز (Windows):
- ببساطة اضغط نقرتين (Double Click) على الملف:
  👉 **`start_app.bat`**
- سيقوم الملف بالتحقق من بايثون، تشغيل قاعدة بيانات SQLite والخادم، وفتح المتصفح تلقائياً على الرابط:
  `http://localhost:8000`

### أو من خلال موجه الأوامر (Terminal / Command Prompt):
قم بفتح المجلد واكتب الأمر التالي:
```bash
python run_python.py
```
(أو `python3 run_python.py` على أنظمة Mac / Linux).

---

## 💻 طريقة تحويل التطبيق إلى ملف تشغيلي EXE (يشتغل بدون بايثون):

لتحويل التطبيق إلى ملف **`CorpConnect.exe`** مستقل يمكنك تشغيله على أي جهاز ويندوز مباشرة:

### الطريقة السريعة والتلقائية (بنقرة زر):
1. قم بالضغط مرتين (Double Click) على الملف الجاهز:  
   👉 **`build_exe.bat`**
2. سيقوم تلقائياً بتثبيت أداة `pyinstaller` وتجميع كافة ملفات التطبيق وقاعدة البيانات في ملف واحد.
3. عند انتهاء العملية، ستجد ملف البرنامج داخل مجلد جديد اسمه **`dist`**:  
   👉 **`dist/CorpConnect.exe`**

### أو عبر سطر الأوامر يدويّاً (Manual):
1. افتح موجه الأوامر (CMD) في مجلد المشروع واكتب:
   ```bash
   pip install pyinstaller
   ```
2. بعد اكتمال التثبيت، اكتب الأمر التالي:
   ```bash
   pyinstaller --onefile --name "CorpConnect" run_python.py
   ```
3. ستجد الملف الناتج في مجلد `dist/CorpConnect.exe`.

> **ملاحظة مهمة:** ملف `CorpConnect.exe` الناتج مستقل بذاته تماماً، يمكنك نقله إلى أي جهاز كمبيوتر يعمل بنظام ويندوز وتشغيله بنقرة زر واحدة دون الحاجة لتثبيت بايثون أو أي برامج أخرى!

## 🌟 مميزات نسخة بايثون:
1. **Zero External Dependencies**: تعمل بمكتبات بايثون القياسية بالكامل (`sqlite3`, `http.server`, `json`, `hashlib`). لا تحتاج لتنفيذ `pip install`.
2. **قاعدة بيانات مدمجة**: تستخدم `corp.db` (SQLite) ويتم إنشاء الجداول والمستخدم الافتراضي تلقائياً.
3. **لوحة تحكم متكاملة**:
   - إدارة الموظفين (إضافة، تعديل، حذف بواسطة زر الحذف المطور).
   - تسجيل الحضور والانصراف الفوري.
   - متابعة الإجازات والطلبات وموافقة/رفض المدير مع إضافة الملاحظات.
   - كشوفات ومسير الرواتب الشهرية وحساب الصافي.
   - نشر وحذف التعميمات والإعلانات الإدارية.
4. **واجهة باللغة العربية بالكامل (RTL)** متجاوبة مع كافة الشاشات والأجهزة.
